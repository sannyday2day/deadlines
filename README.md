# Deadlines

A tiny calendar for class deadlines, quizzes and to-dos. One HTML file, no build step.

- **Live:** https://sannyday2day.github.io/deadlines/
- Works offline and can be installed to your phone's home screen ("Add to Home Screen").
- Data is stored in your browser. Optional sync between devices goes through a secret
  GitHub Gist: tap **Sync** in the app and paste a GitHub token that has only the `gist` scope.
