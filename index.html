☁ Sync between devices

Your calendar gets saved to a secret Gist on your GitHub account, so your phone and laptop show the same stuff. Works offline too — changes sync when you're back online.

  1. Create a GitHub token →
    The gist box is already ticked — don't tick anything else. Set Expiration to No expiration, hit Generate token at the bottom, and copy it.
  2. Paste it here:
  3. On your other devices: open the app, tap ☁ Sync, paste the same token. Keep it somewhere (notes app / password manager).
